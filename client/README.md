# EchoSight — Accessible Voice Client & UI Prototype

This directory contains the phone-first web interface and simulated voice client for **EchoSight**, adhering strictly to the accessibility and design constraints in `DESIGN.md` and `ACCESSIBILITY.md`.

## Features
- **Surroundings Mode (Flagship Screen):** Continuous spatial visual description at a steady ~5-second cadence (~12 calls/minute).
- **Visual Analysis:** Deep structured walkthroughs for still charts, short video clips, and sports match scorecards.
- **Strict Accessibility (WCAG-AA/AAA):** High-contrast color palette, solid 2px focus rings, semantic HTML5, zero decorative emojis or glowing effects.
- **Voice-First Navigation:** Spoken greeting via Web Speech Synthesis, screen-reader polite live regions, and hands-free interruption flows.
